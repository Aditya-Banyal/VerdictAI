VerdictAI Project Overview
VerdictAI is an AI-powered legal document assistant. Users upload legal documents (contracts, agreements, judgments) and have conversational interactions with AI to ask questions about them in plain English.
________________________________________
📁 File Structure & Purpose
Public/Marketing Pages:
•	index.html - Landing page with hero section, feature showcase, and CTAs ("Launch Workspace")
•	about.html - About the product
•	pricing.html - Pricing plans
•	register.html - User registration form
Authentication:
•	login.html - Sign-in form with email/password and social login options (Google, GitHub)
App Pages (After Login):
•	dashboard.html - User command center showing stats:
o	Documents count
o	Questions asked
o	Citations found
o	Storage usage bar
•	workspace.html - Core feature - Two-panel layout:
o	Left panel (68%): PDF viewer with zoom, page navigation, search
o	Right panel (32%): AI copilot chat interface for asking questions about the document
•	upload.html - Document upload interface:
o	Drag-and-drop zone for PDF, DOCX, PNG, JPG files
o	Progress tracking UI
o	Ready state indicator
•	documents.html - Document library/search
•	history.html - Chat/query history
•	settings.html - User preferences (theme, accent color, motion, density)
Static Assets:
•	style.css - Premium dark glass design system:
o	Color palette (indigo primary, cyan accent, glassmorphism)
o	Aurora background with animated blobs
o	Bootstrap integration
o	Component styles (buttons, forms, cards, modals)
•	script.js - JavaScript learning framework (currently empty):
o	Pre-defined element IDs ready for student implementation
o	Navigation logic, form validation, upload handling, workspace interactions
________________________________________
🎨 Design System
•	Theme: Dark mode with purple/blue gradient accents
•	Effects: Glassmorphism, blur effects, animated background blobs
•	UI Components: Custom buttons, cards, forms with premium styling
•	Responsive: Mobile-first, works on all screen sizes
________________________________________
🔄 User Workflow
1.	Land on index.html → Marketing page
2.	Sign Up/Login → register.html / login.html
3.	Upload document → upload.html
4.	Use workspace → workspace.html (split-view: PDF + AI chat)
5.	Track activity → dashboard.html, history.html, documents.html
6.	Customize → settings.html
